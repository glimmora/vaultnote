📋 How to Use

  1. Start Emulator: Click "Start Emulator" to boot the Android virtual device
  2. Install APK: Click "Install APK" to install VaultNote on the emulator
  3. Launch App: Click "Launch App" to open VaultNote
  4. Control: Use the control panel to navigate the emulator
  5. View: Use scrcpy command in terminal to see the emulator screen

💡 Tip: For visual access, run in terminal: scrcpy -s emulator-5554
