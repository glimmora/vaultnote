🎮 How to Access VaultNote

Option 1: Using scrcpy (Recommended)

  1. Open a new terminal
  2. Run: scrcpy -s emulator-5554
  3. This will open a window showing the emulator screen
  4. You can interact with the emulator using your mouse and keyboard

Option 2: Using Android Studio

  1. Open Android Studio
  2. Go to Tools → Device Manager
  3. You should see "Android_SDK_built_for_x86_64" running
  4. Click on it to open the emulator window

Option 3: Manual APK Installation

  1. Wait for emulator to fully boot (may take 2-3 minutes)
  2. Run: adb install -r /home/blue/projects/vaultnote/flutter/build/app/outputs/apk/release/app-universal-release.apk
  3. Once installed, find VaultNote in the app drawer

🔧 Troubleshooting

# Check if emulator is running
ps aux | grep emulator | grep -v grep

# Check emulator logs
tail -f /home/blue/projects/vaultnote/emulator/emulator_final.log

# Restart emulator if needed
adb emu kill
nohup /home/blue/sdk/android/emulator/emulator -avd vaultnote_default -no-audio -no-window -no-accel -gpu swiftshader_indirect -port 5554 &

# Force install APK
adb push /home/blue/projects/vaultnote/flutter/build/app/outputs/apk/release/app-universal-release.apk /data/local/tmp/vaultnote.apk
adb shell pm install /data/local/tmp/vaultnote.apk

📝 Notes

  • Emulator is running in software rendering mode (no hardware acceleration)
  • Cold boot takes 2-3 minutes on first run
  • APK installation may fail due to storage manager issues in software mode
  • Use scrcpy for best visual access to the emulator
  • Web control panel is available at http://localhost:8090/
